# GitHub Profile setup

This package is designed for `Sai-Developer-1405/Sai-Developer-1405`.

## Upload

Copy **all contents** of this package into the profile repository and push them to the default branch.

## Live GitHub Dashboard

The README dashboard uses local SVG assets generated by GitHub Actions, so the profile does not depend on fragile third-party image URLs for the dashboard itself.

The dashboard contains:

- **Live GitHub statistics** — repositories, stars, contributions, followers, pull requests and issues.
- **Daily developer signal** — refreshed using the Asia/Kolkata timezone.
- **Contribution Snake** — generated from the `Snake and Commits` action using the live contribution graph.
- **Contribution Candles** — 52-week and current-month contribution charts generated from GitHub contribution data.

The workflow `.github/workflows/live-dashboard.yml` refreshes:

`assets/github-stats.svg`  
`assets/daily-signal.svg`  
`assets/snake.svg`  
`assets/chart-year.svg`  
`assets/chart-month.svg`

It runs:

- on pushes to `main` that change something outside `assets/**`
- every 12 hours
- manually from **Actions → live github dashboard → Run workflow**

The README points directly to `main/assets/`, so the dashboard updates without editing the README.

## GitHub Actions permissions

Open:

**Settings → Actions → General → Workflow permissions**

Set **Read and write permissions** for `GITHUB_TOKEN`.

Then push the package. Run the workflow once from the **Actions** tab if you want the live assets populated immediately.

Upload the complete package, including:
